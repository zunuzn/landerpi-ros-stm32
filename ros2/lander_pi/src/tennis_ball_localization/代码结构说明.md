## 可复用核心代码

### `src/tennis_ball_detector.py`

单张图像的 YOLO 检测器。输入 OpenCV 图像，输出网球检测框、中心点和置信度。

后续 ROS 节点可以直接复用这个类：

```python
from src.tennis_ball_detector import TennisBallDetector
```

### `src/tiled_tennis_ball_detector.py`

分块检测器。把 `1280x800` 图像切成重叠的 `640x640` 图块，检测后把坐标还原到整图，再合并重复框。

这是当前远处网球检测的主要检测入口。

### `src/stable_tennis_ball_tracker.py`

多目标稳定层。负责跨帧维护 `track_id`、平滑位置和短时丢失保持，不负责选择导航目标。

### `src/tennis_ball_depth_locator.py`

深度取样和相机坐标换算。输入全图像素坐标和深度图，输出：

```text
camera_x_m
camera_y_m
camera_z_m
```

ROS 阶段仍需替换为真实 `CameraInfo` 内参。

## 可直接运行的脚本

### 手机照片预处理

```powershell
.\.venv\Scripts\python.exe scripts\prepare_camera_resolution.py `
  --source photo `
  --out inputs `
  --mode letterbox
```

### 图片 YOLO 分块检测

```powershell
.\.venv\Scripts\python.exe scripts\test_yolo_tennis_ball.py `
  --source inputs `
  --out outputs\tiled_test `
  --tiled
```

### 从视频抽帧

```powershell
.\.venv\Scripts\python.exe scripts\extract_video_frames.py `
  --source inputs `
  --out dataset_source\images `
  --every 30
```

### 自动预标注抽帧图片

```powershell
.\.venv\Scripts\python.exe scripts\autolabel_tennis_ball.py `
  --images dataset_source\images `
  --labels dataset_source\labels `
  --preview-dir outputs\autolabel_preview `
  --conf 0.25 `
  --tiled `
  --write-empty
```

预标注结果必须人工复查：

```text
真实网球漏标 -> 补框
误检物体被框出 -> 删除框
框偏移明显 -> 微调
没有网球的图片 -> 保留空标签
```

### 将标注好的 1280x800 图像切成 640x640 训练块

```powershell
.\.venv\Scripts\python.exe scripts\build_tiled_yolo_dataset.py `
  --images dataset_source\images `
  --labels dataset_source\labels `
  --out tennis_ball_dataset `
  --val-ratio 0.2 `
  --include-empty-tiles `
  --empty-tile-ratio 2.0
```

输出会生成：

```text
tennis_ball_dataset/
├── images/train
├── images/val
├── labels/train
├── labels/val
└── tennis_ball.yaml
```

### 开始微调训练

```powershell
.\.venv\Scripts\python.exe scripts\train_tennis_ball.py `
  --model models\tennis_ball_best.pt `
  --data tennis_ball_dataset\tennis_ball.yaml `
  --epochs 100 `
  --imgsz 640 `
  --batch 16 `
  --device 0
```

训练结果保存到：

```text
runs/tennis_ball_ft_v1/weights/best.pt
```

### 视频预处理和分块检测

假设原始视频为 `photo\court_4k.mp4`，分辨率为 `3840x2160@30fps`：

```powershell
.\.venv\Scripts\python.exe scripts\prepare_camera_resolution.py `
  --source photo\court_4k.mp4 `
  --out inputs `
  --mode letterbox
```

输出文件为：

```text
inputs/court_4k_1280x800.mp4
```

原始视频是 `16:9`，目标画面是 `16:10`，letterbox 会生成 `1280x720` 有效画面，并在上下各补约 `40px` 黑边。输出视频保持原始 `30fps`，但不保留音频。

```powershell
.\.venv\Scripts\python.exe scripts\test_yolo_video.py `
  --source inputs\court_4k_1280x800.mp4 `
  --conf 0.25 `
  --tiled `
  --save-debug `
  --debug-dir outputs\video_tiled_test
```

### 摄像头或视频测试

## 文件判断规则

以后新增代码时：

```text
需要被ROS或其他程序复用 -> 放入 src/
只负责命令行测试或读取文件 -> 放入 scripts/
模型文件 -> 放入 models/
结果文件 -> 放入 outputs/
```

`scripts/` 中的文件不是最终 ROS 节点，只是 Windows 阶段的测试入口。后续 ROS 集成主要复用 `src/` 中的四个核心模块。
